###终端 1：启动完整系统

  cd $DELIVERY_ROOT
  ./Scripts/start_three_go2_dynamic_tracking.sh

  脚本会自动打开多个终端、启动三只 Go2，并最终启动行人。


###终端 2：监控动态感知角色分配

  cd $DELIVERY_ROOT
  source /opt/ros/humble/setup.bash
  source go2_ws_v2/install/setup.bash

  ros2 topic echo \
    /target_role/perception_robot \
    std_msgs/msg/String \
    --once \
    --qos-durability transient_local

###终端 3：监控阶段切换

  cd $DELIVERY_ROOT
  source /opt/ros/humble/setup.bash
  source go2_ws_v2/install/setup.bash

  ros2 topic echo \
    /dynamic_encircle/handoff_state \
    std_msgs/msg/String \
    --qos-durability transient_local

    完整流程是：
    ROLE_WAIT
    ↓
    NAV2_ACTIVE
    ↓
    ARRIVAL_HOLD
    ↓
    NAV2_CANCELLING
    ↓
    WAITING_FOR_STOP
    ↓
    WAITING_FOR_MADDPG_READY
    ↓
    ENABLING_MADDPG
    ↓
    MADDPG_ACTIVE
