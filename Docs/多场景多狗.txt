===================================== 多场景多狗启动命令 ========================================

目标：
1. 在 qy / forest / airport 场景中导入三只 Go2。
2. 每只 Go2 带 3D Velodyne 点云和轻量 RGB 相机。
3. 三只 Go2 使用 go2_1 / go2_2 / go2_3 命名空间，键盘独立控制。

【重要】
1. 跑任何 ROS 命令前先 conda deactivate，确认 which python3 为 /usr/bin/python3。
2. 第一次使用前先编译工作空间，并安装依赖：

sudo apt install xterm ros-humble-teleop-twist-keyboard ros-humble-velodyne-description ros-humble-velodyne-gazebo-plugins

export DELIVERY_ROOT=/home/wangantong/KD_all/go2_target_seek_delivery
cd $DELIVERY_ROOT/go2_ws_v2
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash

===================================== 公共环境 ==================================================

每个终端都先执行一次：

===================================== 终端 1：启动场景 ==========================================

三个场景三选一，只启动世界，不导入狗。

城市 / target_seek 场景：

ros2 launch go2_config gazebo_target_seek_world.launch.py gui:=true world:=$QY_MODEL_ROOT/target_seek

森林场景：

ros2 launch go2_config gazebo_target_seek_world.launch.py gui:=true world:=$KD_MODEL_ROOT/world/forestV3.world

机场场景：

ros2 launch go2_config gazebo_target_seek_world.launch.py gui:=true world:=$KD_MODEL_ROOT/world/airport

===================================== 终端 5：键盘控制 ==========================================

export DELIVERY_ROOT=/home/wangantong/KD_all/go2_target_seek_delivery
cd $DELIVERY_ROOT/go2_ws_v2
source /opt/ros/humble/setup.bash
source install/setup.bash

export KD_MODEL_ROOT=$DELIVERY_ROOT/KD_MODEL
export GAZEBO_MODEL_PATH=$QY_MODEL_ROOT/models:$KD_MODEL_ROOT/models:$GAZEBO_MODEL_PATH
export GAZEBO_MODEL_DATABASE_URI=""

ros2 launch go2_config teleop_three_go2.launch.py

说明：
1. 弹出的 go2_1 teleop / go2_2 teleop / go2_3 teleop 分别控制三只狗。
2. 鼠标点中哪个窗口，键盘就控制哪只狗。
3. 常用键：i 前进，, 后退，j 左转，l 右转，k 停止。

如果按键有 /go2_i/cmd_vel 输出但狗不动，先取消物理暂停：

ros2 service call /unpause_physics std_srvs/srv/Empty {}

===================================== 终端 7：单独查看相机 ======================================

每个相机可以单独开一个 rqt_image_view：

ros2 run rqt_image_view rqt_image_view /go2_1/camera/image_raw
ros2 run rqt_image_view rqt_image_view /go2_2/camera/image_raw
ros2 run rqt_image_view rqt_image_view /go2_3/camera/image_raw

===================================== 常见检查命令 ==============================================

查看三只狗点云话题：

ros2 topic list | grep velodyne_points

查看三只狗相机话题：

ros2 topic list | grep camera/image_raw

查看某只狗是否收到键盘速度命令：

ros2 topic echo /go2_1/cmd_vel

查看某只狗控制器状态：

ros2 control list_controllers -c /go2_1/controller_manager

===================================== 注意事项 ==================================================

1. qy 场景已实际测试成功。
2. forest / airport 使用同一套三狗导入链路，区别只在终端 1 启动的 world 路径。
3. forest 场景历史记录中提到过可能有倾倒情况，如果出现翻倒，先降低负载，逐只导入并等待稳定。
4. 三狗 3D 雷达和三路相机同时运行负载较高，点云频率低于 10Hz 属于常见现象。
5. 如果 Gazebo 旧进程残留，先清理：

pkill -f gzserver
pkill -f gzclient
